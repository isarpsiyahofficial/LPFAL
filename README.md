# LP FAL

Android üzerinde yerel Qwen tabanlı Kahve Falı + Tarot Falı uygulaması.

## V1 zorunlu dokümanları

Geliştirme ve final kontrolünde aşağıdaki üç dosya **birlikte** takip edilir:

1. [`SPECIFICATION.md`](./SPECIFICATION.md) — ürün ve teknik şartname.
2. [`TODO.md`](./TODO.md) — faz bazlı yapılacaklar listesi ve bitiş kriterleri.
3. [`V1_RELEASE_GATES.md`](./V1_RELEASE_GATES.md) — eksik kontrolünde bulunan ek bloklayıcı release şartları.

`V1_RELEASE_GATES.md` opsiyonel not değildir; Faz 18 final kontrolünün zorunlu girdisidir.

V1 tamamlanmadan kapsam dışı özellik eklenmez.
