# LP FAL UI Design References

Bu klasördeki JPG dosyaları yalnız **görsel kompozisyon referansıdır**. Uygulama ekranları bu JPG'leri tam ekran screenshot olarak kullanmaz; metin, buton, navigasyon, Premium etiketi ve etkileşimler Flutter widget'larıyla oluşturulur.

## Premium copy kuralı

- Kullanıcıya görünen plan/özellik adı: **Premium / LP FAL Premium**.
- Eski plan etiketi hiçbir yeni mockup veya runtime ekranda kullanılmaz.
- Süre/abonelik çağrıştıran paket adı kullanılmaz.
- Satın alma açıklaması: **Tek seferlik satın alım · Abonelik değildir.**

Bu klasördeki eski raster JPG'nin içine gömülü bir legacy yazı varsa bu yazı ürün gereksinimi olarak kabul edilmez ve runtime'da kopyalanmaz.

Yeni veya yeniden üretilen tasarım referansı bu standarda uymadan commit edilemez.
